# Mod Sync

Moves your mod *list* between devices instead of copying files (which fails because
mods ship different builds per platform).

1. On device A: main menu -> **Mod Sync** button -> **Copy Mod List**.
2. Send the copied text to device B (Discord, iMessage, notes...).
3. On device B: copy that text, open **Mod Sync** -> **Import**.
4. Matching builds are downloaded from the Geode index. Restart the game when done.

Mods that are not on the Geode index, or have no build for the device, are listed as skipped.
